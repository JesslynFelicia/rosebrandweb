# Rose Brand Web

Static landing page untuk brand Rose Brand dengan section hero, produk, resep, artikel, footer, dan carousel yang responsif untuk desktop maupun mobile.

## Preview

Halaman utama ada di `index.html`. Project ini tidak butuh build step untuk dijalankan sebagai website statis.

## Fitur

- Responsive layout untuk desktop, tablet, dan mobile.
- Hero carousel dengan swipe support di mobile.
- Carousel Produk Kami dan Jelajah Resep dengan indikator swipe.
- Navigasi mobile memakai hamburger menu.
- Smooth scroll untuk navigasi anchor.
- Asset visual dipisahkan di folder `assets/`.



## Cara Menjalankan Lokal

Karena ini static site, cukup buka `index.html` langsung di browser.


## Development

File utama yang biasanya diedit:

- `index.html` untuk struktur konten.
- `styles.css` untuk layout, responsive design, dan visual.
- `main.js` untuk menu, smooth scroll, carousel, swipe, dan animasi saat scroll.
- `assets/layers/` untuk gambar-gambar yang dipakai halaman.


## Catatan

Font dimuat dari Google Fonts, jadi preview terbaik membutuhkan koneksi internet. Semua gambar utama disimpan lokal di folder `assets/`.
